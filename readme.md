# MONOFLOW // Minimalist Habit & Expense Studio

Congratulations on building your first full-featured web application!

## Quick Start (Run Offline)
1. Double-click `index.html` to open MONOFLOW in any desktop or mobile browser.
2. All habits, streaks, 7-day consistency matrices, and expenses are saved automatically in your browser's `localStorage`.

## Publish Online for Free (Under 60 Seconds)
1. Go to **Netlify Drop** (`https://app.netlify.com/drop`) or **GitHub Pages** (`https://pages.github.com/`).
2. Drag and drop this `monoflow_starter_kit` folder onto the page.
3. Open your new live URL on your phone and select **Add to Home Screen** (iOS Safari or Android Chrome) to install MONOFLOW as a full-screen monochrome app.
